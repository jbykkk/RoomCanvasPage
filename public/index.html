01 / OVERVIEW

让房间，不止于被看见。

RoomCanvas 将房间重建与日常空间交互连接起来。一份扫描，变成带纹理的三维房间；每件家具，都是可以选中、挪动和重新摆放的独立物体。

从 iPhone 的 LiDAR 与 RoomPlan 扫描出发，项目整合了房间重建、照片物体重建、网页编辑、摄像头手势和 Android 漫游。在真正搬动家具之前，先在三维空间里试一试。

02 / WORKFLOW

扫描，重建，重新想象。

从现实中的房间，到可以自由布置的三维空间。

  1. 01

    扫描房间

    通过 iPhone LiDAR 与 RoomPlan，采集房间结构和图像信息。

    LiDAR + RoomPlan
  2. 02

    重建空间

    还原真实尺寸与纹理，分离家具，并保留可交互的活动部件。

    Room reconstruction
  3. 03

    自由布置

    移动、旋转家具，检查碰撞与支撑，也能从照片添加新物体。

    Object-level editing
  4. 04

    走进新布局

    用手势操作，开合门窗抽屉，或在网页与 Android 中第一人称漫游。

    Web + Android

新物体从另一条路径加入：照片 → 抠图 → 三维重建 → 尺寸标定 → 放入房间。

01 / REARRANGE

先试一试，再搬家具。

选中独立家具，自由移动、旋转和升降。碰撞与支撑检查辅助摆放，撤销、重做和布局自动保存，让每次调整都有余地。

HANDS-ON

用双手，直接与空间对话。

浏览器摄像头识别双手手势：捏住家具拖动，用另一只手切换模式，竖起拇指确认放置。摄像头画面在本机处理。

STEP INSIDE

换个视角，走进你的房间。

在网页或 Android App 中，以第一人称走进房间。转动视角、开合门窗，从空间内部感受新的布局。

致谢与技术基础

RoomCanvas 的房间重建基于 LiteReality-Agent，照片物体重建整合 ViewForge / MV-SAM3D，物体生成使用 TRELLIS.2；浏览器渲染、手势识别与 Android 展示分别基于 Three.js、MediaPipe 和 SceneView / Filament。本站办公室截图基于 LiteReality 官方样例。
